# 🚀 ChatGPT 自动化 v1.0.2 - 在 chatgpt.com 上自动操作 ChatGPT [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**ChatGPT 自动化** 是一款强大的生产力工具，旨在增强您在 ChatGPT.com 上的工作流程。告别手动逐个输入提示词——实现流程自动化，大规模批量生成回复和图片。

-----

## ✨ 主要功能

* **🚀 先进的批处理：** 排队数十个或数百个提示词，让扩展程序自动处理提交和生成。
* **💬 文本处理自动化：** 从 ChatGPT 批量生成文本回复。支持带自定义延迟的多个提示词。
* **🧩 素材生成文本：** 将多张图片或输入组件与每个提示词一起处理。
* **🖼️ 文本生成图片批量处理：** 从文字描述同时创建多张图片。
* **🔄 图片生成图片：** 使用 AI 结合文本提示词对现有图片进行变换和增强。
* **⚙️ 专业控制套件：**
    * **并发提示词：** 同时处理多个提示词以节省时间。
    * **智能延迟：** 设置提示词之间的自定义间隔，以有效管理速率限制。
    * **自动下载：** 自动将最终结果保存到电脑。
    * **自动更改文件名：** 自动重命名已下载文件以保持整洁。
    * **保存到文件夹：** 为每个项目的下载文件指定自定义子文件夹。
* **🎭 自动添加角色图片：** 根据文件名中的角色名称自动匹配并附加图片到提示词。
* **📊 实时队列管理：** 通过侧边面板（Side Panel）中的可视化状态栏和活跃提示词列表监控您的生成进度。
* **📂 有序的文件管理：** 自动将下载内容按项目分类到文件夹中，保持您的工作空间整洁。
* **🖼️ 独立屏自动下载：** 当提示词包含“逐屏执行”“第1屏”“单独图片/单独画布”等独立屏描述时，扩展会在侧边栏标记“独立屏：是”，并按识别出的屏幕数量下载同一回答里的多张图片，而不是只下载第一张。
* **📝 论文主题命名：** 自动下载图片时，会从 `论文内容：` 后面的论文文本中提取标题或第一句，整理成短主题短语作为图片文件名。
* **🔧 快速修复：** 一键工具，用于恢复生成错误。
* **💳 套餐管理：** 登录以查看您的套餐并追踪每日提示词使用情况。
* **🌐 多语言支持：** 提供英文、越南文、中文、韩文、西班牙文和日文版本。

## 📖 使用指南

### 开始使用

1. **访问 ChatGPT**
   - 打开 [chatgpt.com](https://chatgpt.com)
   - 该扩展程序仅在 ChatGPT 页面上运行。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议将其固定以方便访问！

3. **配置批量设置**
   - 在 **控制** 标签页中，您可以设置：
     - **并发提示词：** 同时运行的提示词数量。
     - **提示间隔：** 每次提交提示词之间的等待时间。
     - **保存到文件夹：** 下载文件的子文件夹名称。
     - **自动更改文件名：** 开启/关闭自动文件重命名。

4. **选择模式**
   - 从可用模式中选择：**文本处理**、**素材生成文本**、**文本生成图片** 或 **图片生成图片**。

---

### 1. 文本处理模式

1. 选择 **文本处理** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或者，点击 **或上传 .txt 文件** 从 `.txt` 文件导入提示词列表。
4. 点击 **运行** 开始批量处理。

**示例提示词：**
```
写一封关于项目延误的专业客户邮件。
保持简洁并致歉。

用5个要点总结远程办公的主要优势。

为降噪耳机写一段产品描述。
目标受众：远程办公人员。
```

---

### 2. 素材生成文本模式

1. 选择 **素材生成文本** 模式。
2. 上传您想要包含的图片或组件文件。
3. 输入提示词（用空行分隔）。图片将与每个提示词一起处理。
4. 可选择开启 **自动添加角色图片**，以自动附加文件名与提示词中角色名称匹配的图片。
5. 在 **设置** 中，设置 **每个提示词最大输入图片数**（1–3）以控制每个提示词使用的图片数量。
6. 点击 **运行**。

---

### 3. 文本生成图片模式

1. 选择 **文本生成图片** 模式。
2. 为您的图片输入详细描述（每个提示词之间用 **空行** 分隔）。
3. 在设置标签页中配置所需的 **图片模型**。
4. 点击 **运行**。

**示例提示词：**
```
日出时宁静的山脉风景，金色阳光倒映在湖面上。

夜晚的未来派城市天际线，霓虹灯闪烁，飞车穿梭。

温馨的咖啡馆内部，暖光照明，墙上摆满书架。
```

---

### 4. 图片生成图片模式

1. 选择 **图片生成图片** 模式。
2. 上传您想要变换的源图片。
3. 输入提示词（用空行分隔）。
4. 可选择开启 **自动添加角色图片**，根据文件名自动附加图片。
5. 在 **设置** 中，设置 **每个提示词最大输入图片数**（1–10）。
6. 点击 **运行**。

| **并发提示词数** | 同时处理的提示词数量（1–6）。 |
| **随机延迟** | 处理下一个提示词前的随机等待时间。 |
| **文本模型** | 选择要使用的文本生成模型。 |
| **图片模型** | 选择用于文本生成图片的 AI 模型。 |
| **默认提示词模式选项** | 提示词的默认模式：新建对话或拼接（与下一个合并）。最后一个提示词始终使用新建对话。 |
| **默认图片模式选项** | 图片提示词的默认输入模式：新建图片或使用上一张图片。 |

## 💡 提示与最佳实践

1. **等待时间：** 如果遇到速率限制，请增加设置中的 **随机延迟**。
2. **并发运行：** 建议从 1 个并发提示词开始，根据账号支持情况缓慢增加。
3. **提示词编写：** 尽可能具体！详细的提示词会带来更好的 AI 生成效果。请用清晰的空行分隔多个提示词。
4. **文件组织：** 使用 **保存到文件夹** 字段，将项目下载内容整理到命名子文件夹中。
5. **角色图片：** 将图片文件命名为角色名称（如 `hero.png`、`villain.jpg`），并开启 **自动添加角色图片** 以自动匹配。
6. **提示词拼接（Concat）：** 使用 *拼接* 模式将提示词串联在一起——每个提示词在同一个 ChatGPT 对话中与下一个合并。
7. **图片链式编辑（使用上一张图片）：** 对于图片生成图片，使用 *使用上一张图片* 模式——每个提示词的输出将作为下一个提示词的输入。
8. **快速修复：** 如果生成卡住或出错，请点击控制标签页中的 **修复错误** 按钮。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保您位于 [chatgpt.com](https://chatgpt.com)。如果需要，请刷新页面（Ctrl+R 或 F5）。 |
| **生成错误** | ChatGPT 可能正忙。扩展程序将根据您的 **最大重试次数** 设置自动重试。使用 **修复错误** 手动恢复。 |
| **下载无效** | 确保 Chrome 设置中已 **关闭** "在下载前询问每个文件的保存位置"。 |
| **需要登录** | 请确保您已登录您的 ChatGPT 账户。 |
| **连接错误** | 刷新 ChatGPT 页面（Ctrl+R、F5）并重试。如果问题持续存在，请尝试重新安装扩展程序。 |
