# Gentool Paper Prompt Crawler

Gentool 是一个 Chrome 插件，用来从公开论文 API 检索论文文本，并整理成可直接喂给 GPT / 图像模型的 prompt txt 文件。

它当前使用：

- OpenAlex：检索开放论文元数据和摘要。
- Europe PMC：检索生命科学、医学、环境等方向的开放论文摘要。

插件不会绕过付费墙，不抓登录内容，不批量下载 PDF。

## 功能

- 按一个或多个领域批量搜索论文。
- 每个领域可以从预设下拉框选择，也可以选择“自定义输入”，并单独设置关键词、prompt 数量、论文数量和每篇候选段数量。
- 自动去重、清理摘要文本、筛选较适合做图的论文内容。
- 支持两种 prompt 风格：
  - `单图风格（偏流程图）`：生成一张极简无文字的单图学术示意图，偏扁平分区流程图/机制图。
  - `独立多屏风格`：使用“第 1 屏到第 N 屏逐屏执行”的强约束，更强调每屏单独画布，避免 GPT 拼成一张大图。屏幕数量、前面屏比例和最后一屏比例都可以在界面里修改。
- 生成后可以按领域分别编辑每条 prompt 中“论文内容”前面的提示词，再应用到当前领域文件。
- 结果预览可以选择领域文件，不会把所有领域内容挤在同一个预览框里。

## 安装

从 GitHub clone 项目：

```bash
git clone <your-repo-url>
cd gentool
```

在 Chrome 中加载插件：

1. 打开 Chrome。
2. 进入 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择 clone 下来的 `gentool` 文件夹。

安装后，浏览器右上角会出现 Gentool 插件图标。点击图标会在 Chrome 右侧打开 Gentool 侧边栏。

## 使用

1. 点击 Gentool 图标，在 Chrome 右侧打开 Gentool 侧边栏。
2. 在“Prompt 风格”里选择：
   - `单图风格（偏流程图）`
   - `独立多屏风格`
   选择独立多屏风格时，可以设置屏幕数量、前面屏比例和最后一屏比例。
3. 在“领域任务”里选择领域。预设领域会自动填入英文搜索关键词；选择“自定义输入”时，可以自己输入领域名称和关键词。
4. 用 `+` 增加领域，用 `−` 减少最后一个领域，也可以点每个领域卡片里的“删除”。
5. 每个领域可以设置：
   - 领域
   - 自定义领域名称（仅自定义输入时显示）
   - 搜索关键词
   - Prompt 数量
   - 论文数量
   - 每篇候选段
6. 选择是否同时检索 Europe PMC、是否优先开放论文。
7. 如需让插件直接指定具体卡通风格，勾选“随机指定具体卡通风格”；不勾选则保留 prompt 中原本的随机风格描述。需要插件直接指定最后一屏构图时，勾选“随机指定第4图构图”；不勾选则由 prompt 要求 GPT 自己从构图列表中随机选择。
8. 点击“开始爬取并生成 txt”。
9. 如需调整前缀，在“领域前缀编辑”里选择领域文件，修改提示词前半段，然后点击“应用到当前领域”。
10. 在“结果预览”里选择领域文件并检查内容。
11. 点击“下载文件夹”。

下载结果会按类似下面的结构整理；不同 prompt 之间用两个换行分隔：

```text
multi_domain_prompt_files/
  生物医学与生命科学_prompts.txt
  信息技术与智能科技_prompts.txt
  自定义领域_prompts.txt
```

## 两种 Prompt 风格

### 单图风格（偏流程图）

这个模式还原早期偏单图/流程图方向的效果：

- 固定使用 `Create image with aspect ratio: 16:9`。
- 只生成一张图，不生成多张屏幕。
- 极简无文字，偏扁平矢量学术插画，参考干净医学插画的简洁度，允许少量柔和阴影和轻微体积感。
- 最多 3-5 个主要图形单元，最多 1-3 条主箭头。
- 使用 2-4 个浅色圆角分区或模块。
- 禁止密集纹理、密集碎线、颗粒堆叠、重复图标或节点、复杂微小结构、强高光、照片级 3D。
- 适合生成减法后的论文图形摘要、机制图或偏流程感的单图。

### 独立多屏风格

这个模式更强调避免拼图：

```text
从第1屏开始重新生成单张独立图，逐屏执行：第1屏、第2屏、...、第N屏，生成完一张自动继续下一张，直到第N屏完成。
每一屏都是一张单独图片、单独画布、单独结果；不要四宫格，不要拼图，不要拼版，不要长图，不要把多个结果合成在同一张画布或同一个外框里。
```

默认是 4 屏：前 3 屏为 `1:1` 物件素材图，最后 1 屏为 `16:9` 百科式无文字学术卡通插图。界面里可以把屏幕数量改成 2-10，也可以修改前面屏和最后一屏的比例。

“随机指定具体卡通风格”关闭时，prompt 会保留“可使用但不限于：彩铅感、粉笔感、纸艺剪贴、黏土感、低多边形、漫画分镜、复古科普、等距小模型、线稿填色、玻璃质感卡通、图标玩具感、Q版科普、轻半立体卡通、干净扁平图形、厚描边贴纸、赛璐璐动画、极简线面插画、几何图标卡通、软塑料玩具、泡泡糖高光、拼块积木感、2.5D数字插画、科技UI卡通、童书科普插画、简洁矢量贴纸、信息图标卡通”的随机描述。开启后，插件会为每条 prompt 从这些风格中随机选一个，并直接写入当前 prompt，例如“本条prompt直接指定卡通风格：图标玩具感”，不再让 GPT 自己随机选择。

“随机指定第4图构图”关闭时，最后一屏 prompt 会要求 GPT 从 14 种构图中随机选择一种。开启后，插件会为每条 prompt 从 14 种构图中随机选一个并写入当前 prompt，例如“本条prompt直接指定第4图构图：作用瞬间”。应用前缀到当前领域时，每条 prompt 已经分配到的卡通风格和第4图构图都会保留，不会被第一条覆盖。

如果 GPT 仍然把结果拼成一张图，优先使用这个模式。

## 领域前缀编辑

生成完成后，“领域前缀编辑”可以选择某一个领域文件，并显示该领域第一条 prompt 中 `论文内容：` 前面的完整提示词。修改后点击“应用到当前领域”，插件只会替换这个领域文件里所有条目的前缀，同时保留每条论文文本不变。

## 字段说明

- 领域：预设下拉选项，选择后会自动填入适合公开论文 API 检索的英文关键词。
- 自定义领域名称：选择“自定义输入”时显示，用于 prompt 里的主题领域，也用于生成下载文件名。
- 搜索关键词：传给 OpenAlex / Europe PMC 的关键词。
- Prompt 数量：这个领域最终导出多少条 prompt。
- 论文数量：这个领域检索并保留多少篇论文。
- 每篇候选段：为以后扩展全文段落抽取预留，目前摘要模式主要按论文生成 prompt。
- 同时检索 Europe PMC：开启后会多查生命科学论文库。
- 优先开放论文：开启后尽量只查开放论文。

## 输出结构

插件不会把所有领域混成一个 txt。生成完成后点击“下载文件夹”，会在浏览器下载目录下写入：

```text
multi_domain_prompt_files/<领域名称>_prompts.txt
```

有几个领域任务，就会生成几个 prompt 文件。

## 注意

- 公开 API 有频率限制，批量数量不要一次开太大。
- OpenAlex / Europe PMC 的英文关键词效果最好。
- 如果结果太泛，缩小关键词，例如加入 `cell`, `protein`, `microbiome`, `sensor`, `battery`, `ecosystem` 等具体词。
- 插件不处理登录网站，不抓付费 PDF，不绕过网站限制。
